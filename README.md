# 👁️ The Observer Effect
> *“The Game That Learns You”*

An experimental psychological web game exploring human determinism, pattern recognition, and machine prediction.

---

## 🔮 Concept
The game begins with the simplest choice:
**LEFT or RIGHT?**

As you make decisions, an internal behavioral model silently measures:
- **Spatial Bias** (Left/Right affinity)
- **Neural Latency** (Impulsive, intuitive, deliberative, hesitant)
- **Entropy & Pattern Avoidance** (Run aversion, Shannon entropy across n-grams)
- **Contrarian & Defiance Index** (Reactions to stated predictions)

The moment the machine predicts your next choice, the observer effect takes hold: *can you truly make an independent choice, or are you merely reacting to the forecast?*

---

## 🕹️ Features
- **Procedural Web Audio Engine**: Meditative sine harmonics, singing-bowl resonance, delicate glass chimes, and heartbeat pacing (100% synthesized in-browser, no external audio files).
- **Interactive UI**: Ambient particle constellation canvas, magnetic 3D button tilt, fluid click ripples, and an interactive Neural Resonance Core.
- **Adaptive Scenarios**: 36 trials spanning Calibration, Awakening, Adaptation, and The Final Crucible.
- **Meta-Mind Games**: Memory flashbacks to trial #2, predictive lockout anomalies, and the Triple Prophecy sequence.
- **6 Distinct Endings**:
  1. *The Clockwork Automaton* (Predictable)
  2. *The Stochastic Ghost* (Unpredictable)
  3. *The Puppeteer* (Manipulator)
  4. *Absolute Convergence* (The System Wins)
  5. *The Transcendence* (Discovered the Hidden Rule)
  6. *The Reversal / Symbiosis* (Secret Ending)
- **Psychological Dossier**: Clinical evaluation breakdown with exportable JSON dossier.

## 🚀 Live Demo & Hosting
This project is built with pure, vanilla HTML5, CSS3, and JavaScript—zero dependencies or build steps required.

### Host with GitHub Pages:
1. Push / upload this repository to GitHub.
2. Go to **Repository Settings** ➔ **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
4. Click **Save**. Your game will be live at `https://<username>.github.io/<repository-name>/`!

## ⌨️ Controls
- **Left**: `A` or `Left Arrow` or `1` or Click
- **Right**: `D` or `Right Arrow` or `2` or Click
- **Defiance / Hidden Rule**: `Escape` or Click the center threshold when it materializes
- **Audio Toggle**: Click the audio switch in the upper right
